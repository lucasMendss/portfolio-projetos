SnapClima

  • Página web que exibe informações sobre o tempo de um local informado pelo usuário. Acessa uma API pública de tempo e clima da OpenWeatherMap.
  • HTML, CSS, Javascript e Vercel para a página, Java e Azure para a função sem servidor
  • Repositório e documentação: https://github.com/lucasMendss/Snapclima
  • Acessar página na web: https://snapclima-one.vercel.app

API Rest de Produtos

  • API REST com funcionalidades de criação, listagem, atualização e exclusão de produtos.
  • Feita com Java e Spring Boot para estudo de conceitos essenciais como controllers, services, tratamento global de exceções, DTOs e documentação automática com Swagger/OpenAPI. Trabalha com uma lista de produtos em memória, permitindo operações de CRUD sem banco de dados.
  • Repositório e documentação: https://github.com/lucasMendss/first-spring-web-rest-api

Bot de Figurinhas para Whatsapp

  • Bot que transforma em figurinha qualquer imagem ou GIF enviada no Whatsapp com legenda '!sticker'.
  • Desenvolvido com Node.js. Diante da dificuldade em encontrar bots gratuitos sem limite, decidi criar o meu.
  • Repositório e documentação: https://github.com/lucasMendss/bot-figurinha-whatsapp

Gerenciador de Aluno

  • App desktop para criar, atualizar, pesquisar e deletar cadastros de alunos.
  • Desenvolvido em C# com Windows Forms Application. Utiliza um banco de dados PostgreSQL hospedado na Supabase.
  • Repositório e documentação github.com/lucasMendss/gerenciador-de-aluno-windows-desktop

Gerenciador de Frota

  • Aplicação web com login de administrador para gerenciar veículos de uma frota. Permite listar, filtrar, cadastrar, atualizar e deletar registros.
  • Desenvolvido com Vue.js, JavaScript (API RESTful) e SQLite.
  • Repositório e documentação github.com/lucasMendss/gerenciador-de-frota
